原文：很多人以為 `git pull` 只會下載遠端的變更。其實 `git pull` 不只是下載，而是先執行 `git fetch`，再把遠端分支合併進目前的分支，所以本機和遠端都改了同一段內容時，可能會產生合併衝突。
原文先點出讀者常見的誤解（以為 git pull 只會下載），再更正。這是 skill 規則裡「讀者確實有那個誤解」的保留情況，更正的結構應該保留。
PASS if 結果仍先點出這個誤解、再說明 git pull 實際上會 fetch 再合併，並保留可能產生合併衝突的後果；只做小幅修飾。
FAIL if 刪掉誤解的那一句、只剩下正面說明，或大幅改寫、加入原文沒有的資訊。
