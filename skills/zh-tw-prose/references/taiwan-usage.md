# 台灣用語對照

模型的中文訓練資料以簡體為多，轉成繁體字後常留下對岸的詞。這份表列出常見的詞與台灣的說法，參考 OpenCC 的台灣詞彙表（Apache-2.0）、Mozilla 與 Microsoft 的 zh-TW 在地化指南，以及教育部《重編國語辭典修訂本》。

使用方式：

- 「檢查」欄為「是」的詞，`scripts/check.py` 會直接報錯。這些詞在台灣幾乎不會出現，或一律有更常用的說法。
- 「檢查」欄為「否」的詞，在台灣另有正當意思，例如「菜單」是餐廳的菜單、「程序」是辦事的程序。腳本不檢查，寫的人依語境判斷。
- 「例外」欄列出包含這個詞、但本身是台灣用語的寫法，腳本會跳過它們，例如「演算法」包含「算法」。
- 專案的用詞表優先於這份表。專案有自己的「不要用」清單時，執行 `check.py` 加上 `--glossary`。
- 不確定一個詞在台灣怎麼說時，查教育部國語辭典或國家教育研究院的雙語詞彙，不要憑印象。

## 簡繁轉換殘留

簡體轉繁體時，一個簡體字可能對應好幾個繁體字，轉錯會出現看起來是繁體、但用錯字的情況。腳本不檢查這一類，寫完通讀時留意：

- 「后」與「後」：「後來」「之後」不寫「后」，「皇后」才用「后」。
- 「干」「乾」「幹」：「乾淨」「幹部」「干擾」各不相同。
- 「發」與「髮」：「頭髮」用「髮」。
- 「里」與「裡」：「公里」用「里」，「這裡」用「裡」。
- 「复」轉成「復」「複」「覆」：「複製」「恢復」「回覆」各不相同。
- 「台」與「臺」：兩者都是正確的正體字，同一份文件統一一種即可。
