原文：「這次重寫由 Agent 完成程式修改、相容性修正與部署。我提出保留外觀、網址和功能的要求，快速審查 diff 與組建設定，再操作 Preview 確認後批准發佈。」
第一句把動作藏在名詞裡（重寫、程式修改、相容性修正），主詞是「重寫」；「批准發佈」也偏公文。
PASS if 動作改回動詞，讀起來像作者自己說的話（例如「從改程式、修正差異到部署，都交給 Agent」這類直接說明誰做了什麼的寫法），並保留這些事實：Agent 負責改程式、修正相容性問題、部署；作者只提出保留外觀、網址與功能的要求；作者快速看過 diff 與組建設定；作者操作 Preview 確認後同意發佈。
FAIL if 仍以「重寫由 Agent 完成……」「進行修改」「完成修正」這類名詞化句型為主、刪掉上述任一事實（特別是 Preview 確認或 diff 審查）、加入原文沒有的事實（例如換電腦、耗時、「順利」），或把原有的第一人稱語氣改成正式公文。
