原文：「這組 Skill 適合用 Claude Code 與 GitHub Issues、想讓主流程一路接下去的人。它最大的取捨在審查：只有容易擴散錯誤的 checkpoint 工單先審，其餘集中在開 PR 前審一次，省下逐張審查的時間與額度。實作預設由主 Session 用同一個 Context 完成，只有長 spec 才把工單全部派給 Subagent。」
第一句替讀者對號入座，屬於推銷式的適用對象；「省下逐張審查的時間與額度」把還沒測過的好處寫成事實。
PASS if 「適合……的人」這類推薦句已刪除或改成具體條件（例如只支援 Claude Code 與 GitHub Issues）；「省下時間與額度」沒有被當成已證實的事實（刪掉、改成題目提供的審查次數數字，或明確標成尚未驗證）；並保留這些事實：最大的取捨在審查、只有容易擴散錯誤的 checkpoint 工單先審、其餘在開 PR 前集中審一次、實作預設由主 Session 在同一個 Context 完成、只有長 spec 才把工單全部派給 Subagent。
FAIL if 推薦句仍在、仍斷言省下了時間或額度、加入題目沒有提供的數字或功能、刪掉取捨或實作預設的任一事實，或把整段改成條列。
