原文：「改用公共 DNS 適合處理解析品質、隱私偏好或已確認的 DNS 層問題。先用 `Resolve-DnsName` 驗證，再判斷網站能否開啟；若改動無效或影響整體連線，立即恢復 DHCP，不要繼續亂改 IP 與閘道設定。」
第二句用分號把驗證步驟和失敗處理串在一起，結尾「不要繼續亂改」是說教口氣，而且前文已經教過怎麼恢復。
PASS if 分號不見了，驗證步驟與失敗處理分成不同句子；結尾改成中性的做法說明（例如「把設定恢復成自動取得」），沒有「不要亂改」這類責備或警告；並保留這些事實：公共 DNS 處理的是解析品質、隱私偏好或已確認的 DNS 層問題；先用 `Resolve-DnsName` 驗證，再判斷網站能否開啟；改動無效或影響整體連線時恢復成 DHCP。
FAIL if 仍有分號、仍有「不要亂改」「千萬不要」之類的警告口氣、刪掉上述任一事實，或加入原文沒有的建議（例如重新開機、聯絡網路業者）。
