原文：「我的顯示卡為 RTX 3070，約需要 2.8 秒左右來生成。」「聰明的你會發現生出來的貼圖都不是無縫圖，這個問題我們後續會解決，現在先來快速走一遍匯入到 Unity 場景的工作流程。」
「聰明的你會發現」在稱讚讀者，替讀者預告他會有的反應，沒有資訊。
PASS if 恭維與「你會發現」這類預告已刪除，改成直接陳述「生出來的貼圖不是無縫圖」；並保留這些事實：顯卡是 RTX 3070、生成約 2.8 秒、貼圖不是無縫圖、這個問題後續會解決、現在先快速走一遍匯入 Unity 場景的流程。第一段的措辭可以小修（例如「約……左右」重複），也可以不動。
FAIL if 仍稱讚讀者或預設讀者聰明、仍以「你會發現」之類預告句開頭、刪掉上述任一事實，或加入原文沒有的事實（例如貼圖為什麼不是無縫的原因）。
