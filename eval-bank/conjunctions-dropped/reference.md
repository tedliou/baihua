# 作者發佈的版本

給人對照用，不會送給模型，也不參與評分。取自 vervecode.dev〈Claude Code 壓縮後我的規則還在嗎？讓 Agent 在長對話中持續遵守規則〉的改稿，作者同意公開。第一句開頭的「Claude Code 的對話太長時」是為了出題補上的，第一段第二句是作者親手改的。

````markdown
Claude Code 的對話太長時，會自動把先前的內容壓縮成摘要，因此我們不必開新的對話就能繼續工作。不過，只在碰到特定檔案時才載入的規則，壓縮後只剩摘要，當 Agent 不知道細節，就可能不再遵從規則。有些規則只和特定檔案有關，因此平常不需要佔用 Context，但工作進行到一半時不能忘記。

如果清單的 `Memory files` 底下列出規則檔，就代表它每次啟動都會載入。

如果 Agent 說得出來，就代表 hook 已經把規則放回對話。
````
