原文第一句：「Jev 是 TypeSafe 的決策模型，後端系統串接只需要一個 HTTP POST 請求：送出要判斷的資料 `state` 與一或多個題目，回傳的是各個答案的機率，不會產生文字。」
第一句用 3 個逗號加 1 個冒號切成一串短句，像在列清單，讀起來不順。
PASS if 第一句的冒號與逗號串被合併成連貫的句子（例如用「只要……就能取得……」「並」「且」連接），第一句的逗號不超過 2 個，不再用冒號列舉；並保留這些事實：Jev 是 TypeSafe 的決策模型、後端用一個 HTTP POST 請求送出要判斷的資料 `state` 與題目、取得各個答案的機率、模型只負責判斷、結果要自動執行還是交給人工由程式依機率或 `confidence` 門檻決定。「不會產生文字」與「一或多個」可以保留，也可以刪。
FAIL if 第一句仍是冒號加逗號的清單式寫法或逗號沒有減少、刪掉核心事實（HTTP POST、`state`、機率、程式依門檻決定）、改動 `state` 與 `confidence` 的寫法，或加入原文沒有的事實。
