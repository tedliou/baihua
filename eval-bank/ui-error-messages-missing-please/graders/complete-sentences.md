原文四則：「這個世界封存了，先取消封存」「找不到房間，檢查代碼」「房間有密碼，先在上面輸入」「沒有成功，再試一次」。每則後半都是省略「請」與主詞的命令式短句。
PASS if 輸出仍然是四行，順序不變；後半的要求補成客氣完整的說法（例如加上「請」，或改成「已封存」這類完整狀態），每則仍然一行、一件事；各則的事實都保留：世界被封存、要先取消封存；找不到房間、要檢查代碼；房間有密碼、要先在上方（上面）輸入；沒有成功、要再試一次。
FAIL if 少於或多於四行、合併成一則；加入道歉或裝可愛的詞（例如「哎呀」「抱歉」）；加入原文沒有的原因推測或新步驟（例如「請聯絡房主」）；刪掉任何一則的要求；或把訊息改成冗長的段落。
