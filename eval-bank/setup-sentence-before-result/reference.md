Agent 再次讀取或修改符合的檔案時，只剩摘要的規則會重新載入，在這之前 Agent 只能依照摘要工作。Agent 再讀一次符合的檔案後，帶有 `paths` 的規則會回到對話，畫面也會出現 `Loaded` 開頭的行。
