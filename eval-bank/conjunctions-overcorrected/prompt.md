幫我潤稿技術文章裡的這幾段。讀者正在設定 Claude Code 的 hook，讓規則在對話壓縮後自動回到對話。四段取自同一篇文章的不同地方。

加上這個 hook，規則在壓縮後就會自動放回，而且規則的內容不用修改。

Hook 是 Claude Code 在特定時機自動執行的指令，而這個設定會在每次壓縮後讀取規則檔，並把內容放回對話。開新對話時不會多載入任何內容，而帶有 `paths` 的規則也會照常在碰到符合的檔案時載入。

因為檔案越長，Agent 遵守規則的程度就越低。因此其他規則維持原樣即可。

打開 `.claude/rules/` 裡的規則檔，並刪除開頭類似下面的設定，之後想還原時再加回去即可：

只輸出成品本身，不要加任何說明、前言或改了什麼的清單。
