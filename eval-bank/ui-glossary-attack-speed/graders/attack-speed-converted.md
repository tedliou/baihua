原文三行都用「出手間隔」，其倍率是間隔的倍率：連射 ×0.6、架砲 ×1.5。用詞表規定介面一律寫「攻速」，數字越大越快，所以倍率要取倒數。
PASS if 三行都保留；「出手間隔」全部改成「攻速」；連射的倍率換算成約 ×1.67（1/0.6），架砲換算成約 ×0.67（1/1.5），霰彈那行改成「共用攻速」；其他數字（3 秒、×1.5 散布、12 秒、6 公尺、×1.2、×2、+1）與標點、括號英文名都保持原樣。
FAIL if 仍有「出手間隔」；換成「攻擊速度」「射速」；倍率沒有換算（連射仍是 ×0.6 但寫成攻速，或架砲仍是 ×1.5）；改動其他數字；刪掉冷卻或散布；或增減行數。
